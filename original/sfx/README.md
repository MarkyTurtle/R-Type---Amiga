# Sound effects

The 14 sound effects, extracted from the `$6000` block by `python3 -I tools/extract_sounds.py files sfx` (run in `original/`). They are 8-bit mono WAVs at the game's playback rate (period 428 = 8287 Hz on PAL). The table, triggers and playback code are described in [`../docs/MUSIC.md`](../docs/MUSIC.md).
